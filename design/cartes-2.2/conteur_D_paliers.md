# Cartes 2.2 par palier : conteur D (le Lovecraftien)

Section 6 des consignes : une carte différente par palier, nombres fixes. Budget du palier n = (4 + 6 × coût) × (1 + 0,25 × (n − 1)), tolérance ±15 %. Conventions : « tous » sur dégâts et brûlure ×2,2 ; « tous » sur hésite, affaiblit, vulnérable, brise-garde ×2,5 ennemis ; un effet sous condition (`si`) compte pour moitié ; `ennemiSoin` n = 2,2n ; `ennemiGarde` n = 2n ; `volVie` = moitié des dégâts. Les backgrounds et les secrets restent ceux de `conteur_D.md` (version de référence). Les paliers 7 sont repris tels quels de `conteur_D.md`.
